# 2026-10-29

- 会话滑动续期：`require_login` 中间件在验证通过后，若令牌剩余有效期 < `session_days`/2，自动在响应头 `Set-Cookie` 续发新 token（`token_exp()` 新增解析函数；续期日志 debug 级）。效果：打开页面/调 API 即刷新令牌，持续使用永不掉线，`session_days` 变为「最长不活跃时间」。新增 3 个单测（issue/verify、token_exp 含用户名带点场景、过期拒绝），共 21 测试全过。
- 端到端坑：python 在 Windows 写的 token 文件是 CRLF，WSL `source` 后变量带 `\r`，curl 头带 CR 被 hyper 拒 400 Bad Request（content-length: 0、无 server 特征）；用 `tr -d '\r'` 转换后验证通过（快过期 cookie → 响应带 set-cookie 新 7 天 token；剩余充足不续；bogus → 401）。
- 另注意：`wsl.exe -e bash -lc` 会话结束时 nohup 的后台进程会被杀（跨命令不存活），测试须「启动+验证」放同一条命令。
